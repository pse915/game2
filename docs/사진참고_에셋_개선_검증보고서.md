# 실제 서라벌여중 사진을 참고한 전체 게임 에셋 개선 · 검증 보고서

## 사용한 자료

이번 요청에 제공된 실제 학교 **붉은 벽돌·푸른 곡면 지붕 외관 사진**, **파란 의자와 책상의 교실 사진**, **연한 벽·목재 창틀·테라조 바닥·진분홍 아치가 보이는 복도 사진**, **탑다운 픽셀 RPG 참고 장면**, **4방향 스프라이트 시트 예시**, 이전 게임 프로젝트 소스, 기존 두 개의 통합 개발 프롬프트를 참고했다. 고유한 제3자 에셋 이미지는 게임 PNG에 복사하지 않았다.

> 학교 사진은 실제 공간의 일부를 보여주는 시각 참고 자료이다. 전체 학교의 정확한 방 좌표, 층수·건물동의 상세 높이·복도의 평면 구조를 검증하는 실측 설계도는 아니므로 학교 내 54개 방의 실제 실측 위치 재현을 주장하지 않는다. 외관의 눈에 보이는 긴 붉은 벽돌동과 회색 동, ㄱ자형 게임용 복도는 각각 시각 참고와 기존 사용자 설명에 근거한다.

## 이번에 실제로 생성·교체된 파일

- `frontend/assets/school_exterior.png` — 붉은 벽돌 본관, 푸른 곡면 금속 지붕, 왼쪽 회색 동, 교실 창문, 야외 차양, 운동장
- `frontend/assets/school_hall_1.png` ~ `school_hall_4.png` — 4개 층 ㄱ자형 실내, 사진의 테라조 타일·목재 창틀·진분홍 아치·게시판·문
- `frontend/assets/school_classroom.png` — 사진의 회색 점무늬 바닥, 파란 의자, 밝은 책상, 금속 프레임, 블라인드, 수납장, 교사 책상
- `frontend/assets/building_*.png` — 카페, 빵집, 복지·돌봄 시설, 의료시설, 사무실, 주거시설, 도서관 등 **13종**의 용도별 외관
- `frontend/assets/interior_*.png` — **13종** 용도별 실내 컷어웨이 배경
- `frontend/assets/avatar_0.png` ~ `avatar_5.png` — **6종** 주인공 캐릭터의 상·하·좌·우 방향 4프레임 시트
- `frontend/assets/teacher_00.png` ~ `teacher_16.png` — 17종 담임교사 캐릭터의 4방향 4프레임 시트
- `frontend/assets/tree_0.png` ~ `tree_2.png` — 정원·마을용 나무
- `frontend/game.js` — 새 마을 건물 PNG, 나무 PNG, 캐릭터 애니메이션을 실제 캔버스에 연결
- `frontend/index.html` — 화면에 남아 있던 영어 'SEWOL PORT' 표시를 `서라벌여중`으로 변경
- `frontend/assets/manifest.json` — 총 **60개** PNG 매니페스트 및 프레임·출처 메타데이터

신규 재생성 스크립트: `tools/generate_photo_inspired_assets.py`, `tools/generate_detailed_interiors.py`, 연결 스크립트 `tools/integrate_photo_assets.py`.

## 남아 있는 품질 과제

- 이번 아트는 프로그램으로 그린 오리지널 픽셀 그래픽으로서 예시의 고품질 수작업 JRPG 에셋을 동일 수준으로 재현했다고 볼 수 없다. 재질과 색채를 반영한 **1차 실제 게임 적용판**이다.
- 17개 교실은 학생 책상·블라인드 등 공통 교실 사진 참고 에셋을 사용한다. 학급별 실제 책상 수, 개별 특별실 배치 및 전체 학교 실측 구조는 확인되지 않았다.
- 현재 개별 가구의 충돌/상호작용 영역은 그래픽의 정밀한 형상과 일대일 대응하지 않는다. 기본 입·퇴실, 학교 복도 이동 및 수업 이벤트는 기존 구현에 의존한다.
- 전체 마을의 타일형 지형은 기존 Canvas 렌더러를 유지했다. 학교 내부/건물 외관/13개 용도별 실내/캐릭터 중심으로 먼저 개선했다.
- 게임 내 교실 문패는 데이터 기반으로 출력된다. 긴 공간명은 접근 안내와 실내 헤더에서 확인 가능하나 복도 기본 문패는 짧은 번호다.
- 4방향 애니메이션 프레임은 존재하고 게임에서 움직이지만 달리기 전용 애니메이션과 복잡한 표정 전환은 별도로 제작되지 않았다.
