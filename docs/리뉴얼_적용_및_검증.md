# 《서라벌여중: 나의 미래 다이어리》 — 기존 세월항 프로젝트 리뉴얼 기록

기반: 사용자가 제공한 `sewol-port-rpg(2).zip` 코드 및 서라벌여자중학교 외관 사진.

## 실제 적용된 개선점

### 실제 학교 외관을 참고한 오리지널 픽셀 PNG

- `frontend/assets/school_exterior.png` (320×224, 투명 PNG) 제작 및 Canvas 외관에 렌더링.
- 원본 사진의 **긴 붉은 벽돌 건물, 4개 층의 유리창 반복, 중앙현관 캐노피, 녹색 정문 철제 울타리, 큰 나무와 화단**을 게임용 픽셀 아트로 재구성.
- 학교 지도상의 본관 크기를 기존 6×5 타일에서 10×7 타일로 확장하여 주택형 외관을 탈피.
- **사진을 그대로 잘라 게임에 넣거나 복제한 것이 아니라 직접 도형·색상·픽셀 패턴을 조합한 에셋**.

### 학교 탐험

- `school.py`: 학교 1~4층 복도, 17개 일반 학급, 9종 특별실/지원실의 **가상 탐험용 위치 정보**.
- 17개 학급 담당 교사 이름·교과는 제공된 텍스트 지시서의 표를 반영했으며, 교사별 개인 캐릭터 시트 17개 사용.
- 학교 복도 PNG 4개, 일반 교실 PNG, 교사 스프라이트 시트 19개(17명 사용 + 예비 2종)를 제작.
- 학교 현관 진입, 복도 이동, 교실 입장, 계단을 통한 층간 이동, 교실 나가기, 마을 복귀.
- 일반 교실: 담임·칠판·게시판·책상·자료함 총 5개 조사 활동.
- 특별실: 알림판/활동 책상/자료함 총 3개 조사 활동.
- 활동 결과는 `school_records`에 저장되며, 주제는 기존 교과서 개념 목록과 연동.
- **주의:** 실제 학교 전체 교실배치도 원본은 이 업로드에 없었습니다. 따라서 실제 실내 위치와 구조가 아닌, 주어진 층별 교실·교과 목록을 바탕으로 한 **게임용 축약 배치**입니다. 실제 복도 및 특별실 위치를 검증하지 않았습니다.
- 교사 캐릭터는 가상의 창작물이며 실존 교사의 외모나 발언을 재현하지 않습니다.

### 마을과 생애설계

- 기존 6개 마을 구역, 16개 사건, 청년기→성인기→노년기, 직업·주거·돌봄·사회정책·노후 준비, JSON/SQLite/Google Sheets 설계를 유지.
- `frontend/assets/interior_*.png`로 건물 종류별 13개 실내 배경 제작. 일반 건물에 실제 3개 조사 활동을 연결.
- 활동 결과는 `building_records`로 추가 저장되며 기존 `decisions` 및 엔딩 조건은 변경하지 않음.
- `guide_mode` 설정(친절/기본/자유)을 Python 저장 데이터로 관리. 마을에서는 통행 가능한 타일을 따라 BFS 경로의 **다음 이동 방향**을 계산하며, 친절 모드에서는 경로 점선을 함께 표시. 학교에서는 선택한 교실, 다른 층의 계단, 건물 출구를 안내.
- 새로운 게임은 학교 정문 앞에서 시작하고, **학교 방문은 메인 생애설계의 필수 선행 조건이 아닙니다.**
- 터치 방향키와 상호작용, 안내 모드, 학교 층 이동의 손가락 조작을 지원하며 작은 화면의 조작 버튼은 최소 44 CSS 픽셀 확보.

## 파일·코드

- `school.py`: 학급 및 교사 데이터 단일 출처.
- `content.py`: 확장 학교 콘텐츠 포함, 기존 마을 건물 유지.
- `engine.py`: 기존 저장 스키마 버전 `1` 유지, 기존 선택 저장과 별개로 `school_activity` / `building_activity` / `guide_setting` 검증 및 저장. 이전 저장 데이터에 확장 필드가 없어도 기본값으로 처리.
- `frontend/game.js`: PNG 에셋 로더, 학교 맵/특별실 이동, 학교 NPC 및 조사, 마을 개별 실내, 경로 안내.
- `frontend/style.css`, `frontend/index.html`: 새 게임 제목, 길 안내 모드, 교실 안내 및 터치 UI.
- `tools/generate_school_assets.py`, `tools/generate_interiors.py`: 오리지널 픽셀 PNG 재생성 도구(개발용 Pillow 필요).
- `frontend/assets/manifest.json`: 생성된 PNG 경로와 크기, 출처 정보.

## 직접 수행한 검사

- `python -m unittest discover -s tests -v`: 18개 통과.
- `python -m compileall -q app.py engine.py content.py school.py storage.py`: 통과.
- `node --check frontend/game.js`: 통과.
- `python tools/browser_smoke.py`: 실제 HTML/CSS/Canvas 코드를 오프라인 브라우저에 로드해 외관·복도·교실 렌더링, 학교 입장, 학급 안내도, 교사 상호작용→메시지→Python 저장→브라우저 재동기화, 810px/390px 화면과 조작 타깃을 확인. 페이지 에러 0건.
- 참고: 로컬 웹서버 URL과 `file://` 접근이 브라우저 보안 정책에 차단되어 **브라우저 테스트는 자원을 인라인으로 주입한 격리 모의 실행**에서 수행함.
- 캡처: `docs/업데이트_마을_스크린샷.png`, `업데이트_학교복도_스크린샷.png`, `업데이트_교실_스크린샷.png`, `업데이트_태블릿_화면.png`, `업데이트_모바일_화면.png`.

## 남은 작업 또는 미검증

1. **실제 1~4층 교실 배치도·운동장·급식실·체육관의 사실성은 검증되지 않았습니다.** 실측 도면/사진을 받아 후속 정밀 지도를 완성해야 합니다.
2. 특별실과 마을 건물은 서로 다른 인테리어 및 3개 기록형 조사 요소를 갖지만, 각 방의 고유 미니게임/사건은 아직 충분히 다양하지 않습니다. 일반 교실 구조는 공용 배경 에셋을 사용합니다.
3. 생성 그래픽은 **프로젝트 전용 1차 오리지널 픽셀 아트**입니다. 상업용 고밀도 아틀라스 수준의 손작업 애니메이션이나 고유 초상화 세트는 아닙니다. 기존 마을 NPC의 일부 절차적 Canvas 그래픽도 그대로 남아 있습니다.
4. 학교 활동 저장은 서버와 연계되지만 플레이어 **좌표**는 원본과 같이 `sessionStorage`를 사용합니다. 다른 기기로 이동 시 마지막 칸까지 복원되지 않습니다.
5. 이번 환경에서 Streamlit/Google Sheets 실제 자격 증명 연동·네트워크 부하·실물 iPad 및 Android 태블릿 테스트는 실행하지 못했습니다. 실제 기기의 Safari/Chrome에서 조작과 저장을 검증해야 합니다.
6. 학생 18~20분 완주율과 학습 성취도는 실제 학생을 대상으로 검증하지 않았습니다.
7. 학교 교실 활동은 메인 엔딩의 필수조건이 아닌 선택형 확장입니다. 결혼·출산 선택을 성적화하거나 강제하지 않는 기존 학습 원칙을 유지합니다.

## 실행

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

- 개발용 에셋 재생성: `pip install Pillow && python tools/generate_school_assets.py && python tools/generate_interiors.py` (두 스크립트를 이 순서로 실행해야 매니페스트에 모두 등록됨).
- 브라우저 스모크 테스트: `pip install playwright` 및 Chromium 설치가 필요. `python tools/browser_smoke.py`.
- **원본 세월항 ZIP을 덮어쓰지 말고** 업데이트 저장소에서 별도 배포 테스트 권장. 기존 Google Sheets 탭 `sewol_port_v1`은 그대로 사용합니다.
