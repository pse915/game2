# 50분 수업 운영안 (예시)

**학습 목표**: ① 저출산·고령화의 원인·영향을 생활 문제와 연결한다. ② 가족 친화적 사회 대응을 제안한다. ③ 노후 준비 4개 영역을 활용하여 자신만의 생애 계획을 설명한다.

| 시간 | 활동 | 교사 점검 |
|---|---|---|
| 0~5분 | 선행 개념 간단히 확인, 게임 로그인·입력법 안내 | 결혼·출산을 의무로 표현하지 않기 |
| 5~10분 | 청년기: 직업·주거 선택, 남는 시간은 사건 탐험 | 선우·미라 이벤트 필수 완료 여부 |
| 10~16분 | 성인기: 돌봄 공백 및 정책 선택, 다양한 주민 심화 | 돌봄·정책 문제의 개인/사회 책임 비교 |
| 16~23분 | 노년기: 재무·건강·여가·대인 관계 | 4개 영역 모두 경험 |
| 23~25분 | 생애설계 카드 완성·교사 대시보드 확인 | 시간 여유 학생 자유 탐험 허용 |
| 25~30분 | 소감문 작성 | 교과서 개념 2개 이상 연결 |
| 30~50분 | 2~3인 공유·모둠 토론·전체 정리 | 다양한 삶의 가치를 존중하고 사회적 지원을 토론 |

**현장 조정**: 이 흐름은 설계상의 목표일 뿐, 실제 중학생 집단의 20분 플레이 완료율은 검증하지 않았습니다. 교사는 사전에 2~3개의 기기로 실제 시간을 측정해야 합니다.

**느린 학생**은 오른쪽 상자의 필수 주민 이름과 오른쪽 지도의 해당 구역 터치로 이동합니다. 각 시기의 필수 사건만 선택해도 다음 단계로 갈 수 있습니다. **빠른 학생**은 상점·일터·강가·교류 사건과 일상 미니게임을 탐험합니다.
