# 실제 배포 후 수업 전 점검표
다음 항목은 실제 브라우저·Google 계정이 필요한 수동 승인 게이트입니다. 자동 검사 통과가 이 목록을 대신하지 않습니다.

- [ ] requirements.txt 설치와 `streamlit run app.py`가 성공합니다.
- [ ] Cloud에서 컴포넌트 CSS/JS가 정상 로드되고 검은 화면이 나오지 않습니다.
- [ ] 첫 학번 001을 저장한 뒤 반·학번·PIN으로 최신 로그를 복원합니다.
- [ ] 잘못된 PIN, 다른 반, 잘못된 JSON 파일은 거절됩니다.
- [ ] 확인란 없이 새로시작할 수 없고 기존 기록은 올바른 PIN이 필요합니다.
- [ ] 방향키/WASD, 태블릿 길게 누르기, 손을 뗐을 때 멈춤이 정상입니다.
- [ ] 건물과 NPC를 통과하지 않고 다섯 구역의 모든 포탈이 왕복합니다.
- [ ] 대화 중에는 이동이 멈추고 키보드 포커스가 대화창 안에 머뭅니다.
- [ ] 6퀴즈의 오답 해설과 정답 후 선택 화면이 정상입니다.
- [ ] CH0 C 이후 척척박사 안내로 정책무지 플래그가 해제됩니다.
- [ ] CH1 B 이후 시청 상담으로 3명 분기가, 인사 상담으로 직장 지원 분기가 열립니다.
- [ ] CH3 0명/1명 경로에서 학교·상점·노인 NPC가 달라집니다.
- [ ] CH3 정책카드를 두 번 눌러도 효과가 중복되지 않습니다.
- [ ] CH5 체크리스트 네 항목을 저장하면 A 분기가 열립니다.
- [ ] 미래시장 엔딩홀에서 D→C→A→B 우선순위가 적용됩니다.
- [ ] 최종 기여도·TFR·전국 가정값 표시와 처방 두 가지가 보입니다.
- [ ] 서비스계정을 편집자로 초대한 시트에 logs/results가 생성됩니다.
- [ ] 네트워크/권한을 차단한 테스트에서 CSV 경고가 나오고 게임이 계속됩니다.
- [ ] 교사 CSV 재전송을 두 번 해도 중복 행이 추가되지 않습니다.
- [ ] 개인 JSON 다운로드→시작화면→파일복원으로 같은 진행을 이어갑니다.
- [ ] 교사 비밀번호 없이 결과가 노출되지 않으며 반별 최신 결과 평균이 보입니다.
- [ ] 실제 반 인원 동시 접속 시 응답 시간과 Google API 할당량을 확인합니다.
- [ ] 수업이 끝난 뒤 개인정보 보유기간과 삭제 방법을 학생에게 안내합니다.

## 수동 권장 경로
가족친화 A를 보려면 A→C→A→C→D→A를 선택하고 정책카드·네 영역을 사용합니다.
유지 B를 보려면 A→C→C→B→D→A를 선택하고 정책카드·네 영역을 사용합니다.
초고령 위험 C를 보려면 B→C→C→A→D→A를 선택하고 정책카드·네 영역을 사용합니다.
고립 위험 D를 보려면 C→B→D→C→C→B를 선택하고 지원카드는 사용하지 않습니다.
위 경로는 잠금 해제를 위한 네 영역 점검을 포함합니다. 게임 중 되돌리기 대신 새 게임 또는 개인 저장파일 복원을 사용합니다.
