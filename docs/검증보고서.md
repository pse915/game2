# 초기 버전 검증 보고서 (2026-10-09)

## 이번 제작 환경에서 확인한 사실

1. `python -m unittest discover -s tests -v`: 엔진 진행 조건, 3단계 엔딩 도달, 주요 개념 기록, 중복 이벤트 방어, 복원 및 학생별 기록 분리 등 **10개 자동 테스트 통과**.
2. `python -m compileall -q`: Python 파일 파싱·바이트코드 컴파일 확인.
3. `node --check frontend/game.js`: JavaScript 구문 검사 통과.
4. 로컬 Playwright/Chromium에서 HTML·CSS·Canvas JS를 로드한 다음 Streamlit의 **컴포넌트 메시지 형식을 모방**한 데이터 주입으로 검사. 지도 버튼을 눌러 일터지구로 빠른 이동 → 방향키 이동 → 선우 대화 → 직업 선택 → 지도 이동 → 미라 대화 → 주거 선택 → 다음 생애 버튼 → 성인기 컷신 표시까지 완료했고, 해당 구간 **브라우저 JavaScript 오류 0개**를 확인했습니다.
5. 같은 브라우저 렌더러로 데스크톱(1380px) 및 태블릿 너비(780px) 미리보기 PNG를 만들고 육안으로 확인했습니다.

## 아직 검증하지 못한 사실

- 이 제작 환경에서 `streamlit`과 `gspread`가 설치되어 있지 않고 외부 패키지 저장소 DNS 연결이 실패하여, **진짜 Streamlit 앱의 기동과 Python↔컴포넌트 재실행 동작을 통합 시험하지 못했습니다.** 따라서 실제 배포 작동을 검증했다고 주장하지 않습니다.
- 유효한 Google Sheets 인증정보, 실제 시트, 다수 학생 동시 접속 및 API 사용량을 검사하지 못했습니다.
- iPad Safari / Android Chrome 물리 기기에서 입력 지연, 화면 회전, 키보드 레이아웃, 접근성을 테스트하지 못했습니다.
- 학생 집단에서 15~20분 내 완료하는지 사용성 실험이 없으며, 시나리오 시간 목표는 미검증입니다.
- 16개 NPC 대사 전체와 16개 사건의 모든 UI 분기를 실제 브라우저로 일일이 방문하지 않았습니다.

## 배포 전 합격 기준(권장)

- Streamlit 앱 로그인→선택 2회→브라우저 새로고침→이어하기에서 선택 보존
- 학급 1개 20~30명 동시 로그인·사건 선택에서 저장 성공률, 지연, 충돌 기록
- 학생 각각 다른 학생번호에서 저장 간 교차 노출 없는지 점검
- 휴대 기기에서 길게 누르기·멀티터치·화면 방향 전환 중 입력 멈춤 확인
- **교과 개념 학습**: 저출산·고령화의 원인과 영향, 사회적 지원, 노후 준비 4영역을 학생이 경험했는지 5분 소감문으로 확인
- 반 전체 대상 실제 게임 소요 시간 기록 및 20분 내 엔딩 완료율 점검
- 개인정보 최소 수집, 비밀키 보호, 시트 공유 권한, 수업 종료 후 보유 기간 정하기
