# 《서라벌여중: 나의 미래 다이어리》 실제 사진 및 픽셀 RPG 참고 2차 개선

## 적용 근거와 범위

이번 자료는 사용자 제공 실제 서라벌여중 사진(붉은 벽돌 본관, 푸른 곡면 지붕과 좌측 회색 동, 하늘색 교실 의자·밝은 책상, 테라조 복도·분홍색 아치·목재 창틀) 및 사용자가 제시한 픽셀 RPG 실내·복도/캐릭터 사례를 **시각적 참조**로 사용했다. 그림과 소스의 배경/캐릭터 픽셀은 새로 제작했다. 타 작품의 스프라이트나 맵을 복사하지 않았다.

프로젝트는 앞선 사진기반 리뉴얼 버전을 기반으로 학교 현관/외관, 미래마을 13종 건물 외관과 13종 실내, 나무 3종을 보존하며, **이번 단계에서는 특히 학교 실제 실내와 동적 교실 문패, 스프라이트 시트**를 개선했다.

## 이번 단계의 실제 변경

- `frontend/assets/school_hall_1.png` ~ `school_hall_4.png` (4개) — ㄱ자형 복도 충돌 좌표와 일치하도록 실내 컷어웨이 구조 재작화. 우측 하단의 뜬금없는 실외 잔디/나무 구역을 교실 단면으로 바꾸고, 테라조 바닥, 분홍색 아치, 나무 문, 액자·게시판·시계·정수기·계단과 실내 창틀 재표현.
- `frontend/assets/school_classroom.png` (1개) — 사용자 교실 사진의 파란 책상 의자, 회색 철제 다리, 밝은 책상 상판, 회색 테라조 바닥, 창가 블라인드, 수납장, 칠판 등 적용.
- `frontend/assets/school_room_*.png` (11개) — 과학, 기술, 가정, 컴퓨터, 음악, 미술, 보건, 도서관, 상담, 행정, 체육 계열의 차별화된 내부 배경. 교실 공통 바닥에 시설에 맞는 고유 가구를 그림.
- `frontend/assets/avatar_0.png` ~ `avatar_5.png` (6개) 및 `teacher_00.png` ~ `teacher_16.png` (17개) — 총 23개의 32×48 픽셀, 4방향 × 4프레임 원본 스프라이트 시트 재작화. **실제 교사 얼굴을 재현하지 않은 창작 캐릭터**.
- `frontend/game.js` — 특수 교실 ID에 따라 PNG 자동 선택·로드, 실제 전체 공간명 문패 출력(북측 공간은 지그재그 높이 배치해 겹침 완화), 기존 위치 추적·충돌·선택 기록 유지.
- `frontend/assets/manifest.json` — 신규 11개 실내 에셋 등록, 현재 매니페스트 검사 대상 71개.
- `tools/refine_school_pixel_art.py`, `tools/refine_character_sprites.py` — 이미지 생성 코드 포함하여 재생산 가능.
- `tools/browser_smoke.py` — 과학실·보건실 실내 사진의 실제 캔버스 렌더링 확인용 실행 캡처 추가.

## 실제 실행/검증 결과

- Python `pytest -q` 22개 테스트 완료 (54 subtests): **통과**.
- `node --check frontend/game.js`: **통과**.
- `python tools/validate_assets.py`: **71개 PNG와 매니페스트 검사 통과**.
- Playwright + Chromium HTML5 Canvas 테스트: **통과**, 브라우저 JS 콘솔 예외 **0개**.
- ㄱ자 복도와 등록된 모든 출입문 이동 경로, 보건실/학습지원실 등 공간 진입·퇴장, 계단 층간 이동, 교사 활동 저장 이벤트 및 복원, 모바일 방향패드 롱프레스 동작 **검사 통과**.
- 과학실·보건실 등 차별화된 실내의 브라우저 스크린샷 제작.

## 사용된 자료의 한계 및 실제 미검증 항목

1. 사진은 일부분을 보여 줄 뿐 설계 도면이 아니다. 각 실의 정확한 면적·출입문 간 거리·층별 평면 위치는 **실측 검증하지 않았다**. `school.py`의 ㄱ자형 좌표는 사용자가 제공한 구조 지시와 게임성을 바탕으로 한 근사 모형이다.
2. 프로그램에서 자체 제작한 픽셀 스타일은 참고 이미지와 동일한 수작업 상업용 픽셀 아트 품질을 달성했다고 판단할 수 없다. 특히 특별실 가구 종류는 다양해졌지만 모든 가구에 독립 충돌/애니메이션이 있는 것은 아니다.
3. 이전 리뉴얼의 마을 지형/미니게임/상점/주택용 이미지 대부분은 **보존 및 재사용**했다. 이번 단계에서 모든 마을 에셋을 새로 다시 그린 것은 아니다.
4. 이 실행 환경에 Streamlit 패키지가 설치되지 않아 Streamlit 서버의 종단 간 실행을 확인하지 못했다. 기존 Python·Streamlit 컴포넌트 파일을 보존하였다.
5. 실제 Google Sheets 쓰기·읽기 및 교사용 대시보드의 서버 연결은 필요한 계정/비밀키가 없어 미검증이다. 기존 `storage.py` API/저장 키는 변경하지 않았다.
6. 물리적 iPad/Android 및 학생 20분 수업 현장 테스트는 미실시. 브라우저 뷰포트의 모바일/태블릿 에뮬레이션 검사만 수행했다.

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```

배포 전 외부 연결의 비밀키를 Streamlit secrets로 안전하게 설정한다. `tools/browser_smoke.py`는 Chromium·Playwright 설치가 된 검증용 환경에서만 실행된다.
