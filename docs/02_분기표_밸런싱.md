## 조건부 잠금·보너스와 회복 경로

- CH1 A는 정보 접근성이 필요합니다. CH0 A/B 또는 척척박사 무료 안내로 열립니다.
- CH2 A/B는 안정 주거가 있으면 행복 +4, 돌봄 -3 보너스를 받습니다.
- CH1 D 후 CH2에서는 취업 가능 플래그와 활력 +4가 적용됩니다. 소득은 270만원이며 CH2 D라면 280만원입니다.
- CH3 D는 안정 주거 플래그가 필요합니다. CH1 A/C 또는 시청 안전망 상담으로 열립니다.
- CH4 A는 고용 연결, CH4 D는 직장지원 정보가 필요합니다. 인사담당자 상담은 두 조건을 모두 엽니다.
- CH5 A는 네 영역 점검 저장이 필요합니다. 할머니나 의사에게서 점검합니다.
- 배우자의 직업은 run_id 기반 의사난수로 간호사·공공기관 직원·프리랜서·교사 중 고릅니다. 저장 후 바뀌지 않으며 직업별 점수 차이는 없습니다.

## 사건과 파생 지표

- 32세 이후 국가·사회 책임 정책카드를 사용할 수 있습니다. 한 번만 돌봄 -5, 활력 +6, 행복 +4를 적용하고 정보 접근성을 엽니다.
- 38세 양육비 스트레스는 자녀수×3입니다. 정책카드를 미리 사용하면 max(0, 자녀수×3−4)입니다. 해당 값만큼 행복이 줄고 돌봄이 늘어납니다.
- 무자녀는 38세에 휴직·어린이집 플래그를 제거합니다. 공동육아는 이웃 돌봄으로 유지하며 유연근무도 유지합니다.
- 자녀 결정 뒤 가상TFR<1.30이면 상점이 소등되고 장식 노인 NPC가 구역당 2명에서 6명으로 늘어납니다. 가상TFR<1.00 또는 C 엔딩이면 미래초등학교가 폐교로 표시됩니다. 정책과 선택에 따라 지표와 학교 상태가 다시 계산됩니다.
- 고령화율 변화는 위 표의 선택별 합계입니다. 실제 인구전망 계산이 아닙니다.

## TFR 보너스 표

| 항목 | 값 |
|---|---|
| 공동육아 | +0.10입니다. |
| 휴직·어린이집·유연근무 | 각 +0.05이며 합계 최대 +0.15입니다. |
| 가족가치 학습 | +0.05입니다. |
| 독박·경력단절 | -0.10입니다. |
| 무준비 부양 | -0.10입니다. |
| 정책무지 | -0.05이며 상담·정책카드로 해제됩니다. |

`delta = (자녀수 - 1.30) + 보너스합`이며 `최종 가상TFR = 1.30 + delta`입니다. 동일 제도의 중복 보너스는 없습니다.
